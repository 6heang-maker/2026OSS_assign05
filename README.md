# OSS Assignment 05

Vercel: https://2026-oss-assign05-dun.vercel.app/

## Review

이번 과제에서는 JavaScript를 이용해서 HTML 요소를 동적으로 만들고 수정하는 방법을 배웠다.

CRUD 주제는 Friend Management로 정했다. 
ID, Name, Age, Phone, Email, Group 등의 정보를 사용했다.

친구 정보를 입력하고 버튼을 누르면 새로운 데이터가 추가되고
Array에 저장된 데이터가 출력되도록 만들었다.
수정 버튼을 누르면 기존 친구의 정보가 다시 입력창에 나타나고
내용을 변경한 뒤 Save 버튼을 누르면 기존 정보가 수정된다.
삭제 버튼을 누르면 확인창이 나오고 확인을 누르면 해당 친구의 정보가 삭제된다.

## Difficulties

어려웠던 부분으로는 어디가 틀렸는지 몰랐을 때 였다. 계속 찾다가 
단순한 오타라는 걸 알고 허탈했다. 오타나 틀리게 쓴 부분이 있었는데 
몇 번 더 틀리고는 ai에게 물어보기도 했다. 

처음에는 코드들을 만들면서 교수님의 말씀을 듣지 않고 그냥 흩어놔도 찾을 수 있다는 
생각을 했다. 그런데 오만이었다. 왜 그런 말씀을 하셨는지도 알게 되고 그냥 붙여서
작성하고 근처에 두기로 했다. 

수정 기능에서는 어떤 친구를 수정하고 있는지 기억하는 방법이 어려웠다.
수정 버튼을 눌렀을 때 해당 친구의 정보를 입력창에 넣는 것까지 생각했는데
Save 버튼을 눌렀을 때 어떤 Array 데이터를 바꿔야 하는지가 어려웠다.

그래서 editIndex에 수정할 친구의 위치를 저장하고
friends[editIndex]를 이용해서 값을 바꾸는 방식으로 구현하였다.



## AI / Search Usage

클로드를 사용해서 코드에서 이해되지 않는 부분을 질문하고
오류가 발생한 부분을 확인하였다.

CRUD를 구현하는 과정에서 수정할 데이터를 기억하기 위해 editIndex를 사용하는 방법을
클로드를 통해 알게 되었다. 수업에서 직접 다루지 않은 방식이라 처음에는 이해가 되지 않아
어떤 역할을 하는지 다시 질문하고 코드를 확인하였다.
말고도 다른 모르거나 과정을 어떻게 해야하는지 모를 때 ai에게 질문을 해 어떻게 
사용하는 단어인지 배웠다. indexof()로 이메일을 검사하는 방법도 알았다. 

README를 작성할 때도 내용 정리에 도움을 받았다.


## Reflection

처음에는 수정과 삭제 기능이 복잡하게 느껴졌지만 점점 하면서
익숙해지면 쉽게 원하는 데이터를 찾아서 수정하거나 삭제할 수 있다는 것을 알게 되었다.

아직 모르는게 많다고 느꼈고 막힐 때 ai의 도움 없이 할 수 있게 만들어야겠다. 

아직 JavaScript 코드가 익숙하지 않아서 코드를 작성할 때 시간이 많이 걸리지만
기능을 하나씩 나누어서 구현하면 조금 더 이해하기 쉽다는 것을 느꼈다.

현해보면서 CRUD의 기본 구조를 만들어볼 수 있었고 다음에 비슷한 기능을 
만들 때는 이번 과제보다 조금 더 빠르게 만들 수 있을 것 같다.
